# 🏎️ Street Rush

Joguinho de corrida 2D feito com HTML, CSS e JavaScript.

## Como jogar

- ⬅️ ➡️ ou A / D: dirigir
- ⬆️ ou W: acelerar
- ⬇️ ou S: frear
- Desvie dos carros.
- Sobreviva o máximo possível e bata seu recorde.

## Rodar localmente

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `game.js` e `README.md`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub publicar o site.
